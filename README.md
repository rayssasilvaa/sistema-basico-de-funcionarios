# 👩‍💼 Sistema Básico de Funcionários | Basic Employee Management System


## 🇧🇷 Português

### 📖 Sobre o Projeto
Este projeto consiste em um sistema simples de gerenciamento de funcionários desenvolvido para fins educacionais.

O objetivo é aplicar conceitos fundamentais de programação, como:
- Programação Orientada a Objetos (POO)
- Estrutura de classes
- Manipulação de dados
- Organização de código

O sistema permite representar funcionários e suas informações dentro de um programa.

---

### 🚀 Tecnologias Utilizadas

- Java
- Programação Orientada a Objetos (POO)


### ⚙️ Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/rayssasilvaa/sistema-basico-de-funcionarios.git
```

2. Entre na pasta do projeto:

```bash
cd sistema-basico-de-funcionarios
```

3. Compile o projeto:

```bash
javac Main.java
```

4. Execute o programa:

```bash
java Main
```
---

### 🎯 Objetivo do Projeto

Este projeto foi criado para praticar conceitos básicos de programação em Java e fortalecer habilidades de lógica e organização de código.
